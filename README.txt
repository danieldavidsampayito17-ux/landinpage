PORTAFOLIO WEB — DANIEL SAMPAYO
================================

ESTRUCTURA
- index.html       Página principal
- css/style.css    Estilos, colores y diseño adaptable a móvil
- img/             Foto de Daniel y recursos gráficos originales en CSS
- Font/            Carpeta reservada para fuentes locales

CÓMO USAR
1. Descomprime el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre index.html en el navegador o publica el repositorio en GitHub Pages.

ANTES DE PUBLICAR
- En index.html, cambia tu-correo@ejemplo.com por tu correo real.
- Si quieres, reemplaza el enlace de Instagram por tu perfil.
- La página carga DM Sans y Manrope desde Google Fonts cuando hay conexión. Si necesitas fuentes locales, coloca archivos .woff2 en Font/ y declara @font-face al inicio de css/style.css.

SUBIR A GITHUB
1. Crea un repositorio nuevo en GitHub.
2. Sube index.html y las carpetas css, img y Font (no subas solo el ZIP).
3. En Settings > Pages, configura la publicación desde la rama principal y la carpeta raíz.
4. Guarda y espera el enlace de GitHub Pages.

Las tres imágenes abstractas de proyectos son diseños originales construidos con CSS; son muestras conceptuales, no trabajos de clientes.
